KattuOna-விற்கான API key பெறுங்கள்

தங்கள் சொந்த சர்வரை இயக்குவதற்கு அல்லது KattuOna-வின் உள்ளமைந்த AI-ஐப் பயன்படுத்துவதற்கு பதிலாக, AI-க்காக ஒரு நிறுவனத்திற்கு நேரடியாகப் பணம் செலுத்த விரும்புவோருக்கு.

KattuOna-வின் "ஒரு API key பயன்படுத்து" விருப்பம் பொதுவான OpenAI chat ஃபார்மேட்டைப் பேசும் எந்த நிறுவனத்துடனும் வேலை செய்யும் — இன்றைய காலகட்டத்தில், இவற்றில் பெரும்பாலானவை அப்படித்தான். கீழே ஒன்றைத் தேர்ந்தெடுக்கவும், சைன் அப் செய்யவும், ஒரு key உருவாக்கவும், அதை (அந்த வழங்குநரின் பேஸ் முகவரியுடன்) KattuOna → Settings → AI இன்ஜின் → ஒரு API key பயன்படுத்து-இல் பேஸ்ட் செய்யவும்.

உங்கள் key உங்கள் ஃபோனில் மட்டும் சேமிக்கப்படும். KattuOna இதை நீங்கள் தேர்ந்தெடுத்த நிறுவனத்திற்கு நேரடியாக அனுப்புகிறது, எந்த ஆப்பும் செய்வது போலவே — KattuOna-வின் டெவலப்பர் இதையோ இதைப் பயன்படுத்தும் உரையாடல்களையோ ஒருபோதும் பார்ப்பதில்லை.

மாடல் பெயர்கள் பற்றி: கீழே உள்ள ஒவ்வொரு நிறுவனமும் காலப்போக்கில் பழைய மாடல்களை நிறுத்தி புதியவற்றைச் சேர்க்கும், எனவே இந்தப் பக்கத்தில் அச்சிடப்பட்ட ஒரு மாடல் பெயர் பின்னர் வேலை செய்யாமல் போகலாம் (இந்தப் பக்கத்தின் முந்தைய ஒரு பதிப்பில் இது நடந்தது, அதில் Google பின்னர் அகற்றிய ஒரு Gemini மாடல் பட்டியலிடப்பட்டிருந்தது). KattuOna-வில் உங்கள் பேஸ் முகவரியையும் key-யையும் உள்ளிட்ட பிறகு, அங்கேயே Settings → AI இன்ஜினில் கிடைக்கும் மாடல்களைப் பார்க்கவும்-ஐ தட்டவும் — KattuOna நேரடியாக வழங்குநரிடம், அந்த நேரத்திலேயே, இன்று உங்கள் key-க்கு எந்த மாடல்கள் வேலை செய்கின்றன என்று கேட்கிறது, பழையதாக இருக்கக்கூடிய ஒரு பெயரை டைப் செய்வதற்குப் பதிலாக அவற்றில் ஒன்றைத் தட்ட உங்களை அனுமதிக்கிறது. கீழே உள்ள மாடல் பெயர்கள் நீங்களே ஒரு பெயர் டைப் செய்ய விரும்பினால், ஒரு ஆரம்பப் புள்ளி மட்டுமே.

1. ஒரு வழங்குநரைத் தேர்ந்தெடுத்து ஒரு key பெறுங்கள்

OpenAI

ChatGPT-இன் பின்னணியில் உள்ள நிறுவனம். நம்பகமானது, பரவலாகப் பயன்படுத்தப்படுவது, பயன்பாட்டின் அடிப்படையிலான விலை நிர்ணயம்.

  1. platform.openai.com-க்குச் சென்று ஒரு கணக்கை உருவாக்கவும்.
  2. Billing-இல் ஒரு பேமெண்ட் முறையைச் சேர்க்கவும் (API பயன்பாடு உங்களிடம் இருக்கக்கூடிய எந்த ChatGPT சப்ஸ்க்ரிப்ஷனிலிருந்தும் தனியானது).
  3. API keys-க்குச் சென்று, Create new secret key-ஐ கிளிக் செய்து, உடனடியாக அதை கொப்பி செய்யவும் — இது ஒரு முறை மட்டுமே காட்டப்படும்.
பேஸ் முகவரிhttps://api.openai.com/v1
முயற்சி செய்ய ஒரு மாடல் (கையால் டைப் செய்தால்)gpt-4o-mini (வேகமானது, மலிவானது)

Groq

  1. console.groq.com-க்குச் சென்று Google அல்லது GitHub-உடன் சைன் இன் செய்யவும்.
  2. API Keys → Create API Key, இதற்கு ஒரு பெயர் கொடுக்கவும், கொப்பி செய்யவும்.

Together AI

திறந்த-மூல மாடல்களின் பரந்த தேர்வு, தொடங்குவதற்கு ஒரு சிறிய ஃப்ரீ கிரெடிட்டுடன் பே-ஆஸ்-யூ-கோ.

  1. api.together.ai-க்குச் சென்று சைன் அப் செய்யவும்.
  2. Settings → API Keys, டிஃபால்ட் key-யை கொப்பி செய்யவும் அல்லது புதிதாக ஒன்றை உருவாக்கவும்.

Google Gemini

Google-இன் சொந்த மாடல்கள், இவற்றின் OpenAI-ஒத்த முகவரி வழியாக அணுகக்கூடியவை.

  1. aistudio.google.com/apikey-க்குச் சென்று ஒரு Google கணக்குடன் சைன் இன் செய்யவும்.
  2. Create API key, இதை கொப்பி செய்யவும்.

2. இதை KattuOna-வில் உள்ளிடுதல்

KattuOna → Settings → AI இன்ஜின் → ஒரு API key பயன்படுத்து-ஐத் திறந்து, பிறகு நிரப்பவும்:

  • பேஸ் முகவரி — நீங்கள் தேர்ந்தெடுத்த வழங்குநருக்கு மேலே உள்ள அட்டவணையிலிருந்து சரியான முகவரி.
  • API key — நீங்கள் இப்போது கொப்பி செய்த key.
  • மாடல் — மேலே உள்ள முகவரியும் key-யும் நிரப்பப்பட்டவுடன் கிடைக்கும் மாடல்களைப் பார்க்கவும்-ஐ தட்டவும், KattuOna வழங்குநரிடமிருந்து பெறும் லைவ் பட்டியலில் இருந்து ஒன்றைத் தேர்ந்தெடுக்கவும். இந்தத் துளியை நிரப்புவதற்கான நம்பகமான வழி இது, ஏனெனில் இது எப்போதும் அந்த வழங்குநர் உங்கள் key-க்கு இப்போது வழங்குவதை பிரதிபலிக்கிறது — காலம் கழிந்திருக்கக்கூடிய ஒரு பக்கத்தில் அச்சிடப்பட்ட பெயர் அல்ல.

சேமித்து சோதிக்கவும்-ஐ தட்டவும் — KattuOna ஒரு சிறிய டெஸ்ட் மெஸேஜை அனுப்பி, key, முகவரி, அல்லது மாடல் தவறாக இருந்தால் உடனடியாக உங்களுக்குச் சொல்லும்.

செலவுகள்: மேலே உள்ள ஒவ்வொரு வழங்குநரும் உங்கள் சொந்த பயன்பாட்டின் அடிப்படையில் பில் செய்கிறார் (அல்லது ரேட்-லிமிட் செய்கிறார்). KattuOna-வின் டெவலப்பருக்கு உங்களிடம் என்ன சார்ஜ் செய்யப்படுகிறது என்பதில் தெரிவும் கட்டுப்பாடும் இல்லை — தொடங்குவதற்கு முன் ஒவ்வொரு வழங்குநரின் சொந்த விலை பக்கத்தையும் பார்க்கவும், விலை குறித்து கவனமாக இருந்தால் பயன்பாட்டைக் கண்காணிக்கவும்.
