KattuOna ಗಾಗಿ API key ಪಡೆಯಿರಿ

ತಮ್ಮ ಸ್ವಂತ ಸರ್ವರ್ ಚಲಾಯಿಸುವ ಅಥವಾ KattuOna ದ ಬಿಲ್ಟ್-ಇನ್ AI ಬಳಸುವ ಬದಲು, AI ಗಾಗಿ ಒಂದು ಕಂಪನಿಗೆ ನೇರವಾಗಿ ಹಣ ಪಾವತಿಸಲು ಇಚ್ಛಿಸುವವರಿಗಾಗಿ.

KattuOna ದ "API key ಬಳಸಿ" ಆಯ್ಕೆ ಸಾಮಾನ್ಯ OpenAI ಚಾಟ್ ಫಾರ್ಮ್ಯಾಟ್ ಮಾತನಾಡುವ ಯಾವುದೇ ಕಂಪನಿ ಜೊತೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ — ಈ ದಿನಗಳಲ್ಲಿ, ಇದು ಹೆಚ್ಚಿನವು. ಕೆಳಗಿನಿಂದ ಒಂದನ್ನು ಆಯ್ಕೆ ಮಾಡಿ, ಸೈನ್ ಅಪ್ ಮಾಡಿ, ಒಂದು key ಸೃಷ್ಟಿಸಿ, ಮತ್ತು ಅದನ್ನು (ಆ ಪ್ರೊವೈಡರ್‌ನ ಬೇಸ್ ವಿಳಾಸದ ಜೊತೆ) KattuOna → Settings → AI ಎಂಜಿನ್ → API key ಬಳಸಿ ಗೆ ಪೇಸ್ಟ್ ಮಾಡಿ.

ನಿಮ್ಮ key ಕೇವಲ ನಿಮ್ಮ ಫೋನಿನಲ್ಲಿ ಮಾತ್ರ ಸೇವ್ ಆಗುತ್ತದೆ. KattuOna ಇದನ್ನು ನೀವು ಆಯ್ಕೆ ಮಾಡಿದ ಕಂಪನಿಗೆ ನೇರವಾಗಿ ಕಳುಹಿಸುತ್ತದೆ, ಬೇರೆ ಯಾವುದೇ ಆಪ್ ಮಾಡುವ ಅದೇ ರೀತಿಯಲ್ಲಿ — KattuOna ದ ಡೆವಲಪರ್ ಇದನ್ನು ಅಥವಾ ಇದನ್ನು ಬಳಸುವ ಸಂಭಾಷಣೆಗಳನ್ನು ಎಂದಿಗೂ ನೋಡುವುದಿಲ್ಲ.

ಮಾಡೆಲ್ ಹೆಸರುಗಳ ಬಗ್ಗೆ: ಕೆಳಗಿನ ಪ್ರತಿ ಕಂಪನಿಯೂ ಕಾಲಕ್ರಮೇಣ ಹಳೆಯ ಮಾಡೆಲ್‌ಗಳನ್ನು ನಿಲ್ಲಿಸುತ್ತದೆ ಮತ್ತು ಹೊಸವುಗಳನ್ನು ಸೇರಿಸುತ್ತದೆ, ಹಾಗಾಗಿ ಈ ಪೇಜ್‌ನಲ್ಲಿ ಮುದ್ರಿಸಲಾದ ಒಂದು ಮಾಡೆಲ್ ಹೆಸರು ನಂತರ ಕೆಲಸ ಮಾಡುವುದನ್ನು ನಿಲ್ಲಿಸಬಹುದು (ಇದು ಈ ಪೇಜ್‌ನ ಒಂದು ಮುಂಚಿನ ಆವೃತ್ತಿಯಲ್ಲಿ ಆಗಿತ್ತು, ಅದರಲ್ಲಿ Google ನಂತರ ತೆಗೆದುಹಾಕಿದ ಒಂದು Gemini ಮಾಡೆಲ್ ಇತ್ತು). KattuOna ನಲ್ಲಿ ನಿಮ್ಮ ಬೇಸ್ ವಿಳಾಸ ಮತ್ತು key ದಾಖಲಿಸಿದ ನಂತರ, ಅಲ್ಲಿಯೇ Settings → AI ಎಂಜಿನ್‌ನಲ್ಲಿ ಲಭ್ಯ ಮಾದರಿಗಳನ್ನು ನೋಡಿ ಟ್ಯಾಪ್ ಮಾಡಿ — KattuOna ನೇರವಾಗಿ ಪ್ರೊವೈಡರ್‌ನಿಂದ, ಆಗಲೇ, ಇಂದು ನಿಮ್ಮ key ಗೆ ಯಾವ ಮಾಡೆಲ್‌ಗಳು ಕೆಲಸ ಮಾಡುತ್ತವೆ ಎಂದು ಕೇಳುತ್ತದೆ, ಮತ್ತು ಹಳೆಯದಾಗಿರಬಹುದಾದ ಹೆಸರನ್ನು ಟೈಪ್ ಮಾಡುವ ಬದಲು ಒಂದನ್ನು ಟ್ಯಾಪ್ ಮಾಡಲು ಅನುಮತಿಸುತ್ತದೆ. ಕೆಳಗಿನ ಮಾಡೆಲ್ ಹೆಸರುಗಳು ನೀವು ಸ್ವತಃ ಒಂದು ಹೆಸರು ಟೈಪ್ ಮಾಡಲು ಇಚ್ಛಿಸಿದರೆ ಕೇವಲ ಒಂದು ಆರಂಭಿಕ ಬಿಂದು.

1. ಒಂದು ಪ್ರೊವೈಡರ್ ಆಯ್ಕೆ ಮಾಡಿ ಮತ್ತು ಒಂದು key ಪಡೆಯಿರಿ

OpenAI

ChatGPT ಹಿಂದಿನ ಕಂಪನಿ. ಭರವಸೆಯುಳ್ಳ, ವ್ಯಾಪಕವಾಗಿ ಬಳಸಲ್ಪಡುವ, ಬಳಕೆ-ಆಧಾರಿತ ಬೆಲೆ.

  1. platform.openai.com ಗೆ ಹೋಗಿ ಒಂದು ಖಾತೆ ಸೃಷ್ಟಿಸಿ.
  2. Billing ನಲ್ಲಿ ಒಂದು ಪೇಮೆಂಟ್ ವಿಧಾನ ಸೇರಿಸಿ (API ಬಳಕೆ ನಿಮಗೆ ಇರಬಹುದಾದ ಯಾವುದೇ ChatGPT ಸಬ್‌ಸ್ಕ್ರಿಪ್ಷನ್‌ನಿಂದ ಬೇರೆಯಾಗಿದೆ).
  3. API keys ಗೆ ಹೋಗಿ, Create new secret key ಕ್ಲಿಕ್ ಮಾಡಿ, ಮತ್ತು ಅದನ್ನು ಕೂಡಲೇ ಕಾಪಿ ಮಾಡಿ — ಇದನ್ನು ಒಂದೇ ಬಾರಿ ತೋರಿಸಲಾಗುತ್ತದೆ.
ಬೇಸ್ ವಿಳಾಸhttps://api.openai.com/v1
ಪ್ರಯತ್ನಿಸಲು ಮಾಡೆಲ್ (ಕೈಯಿಂದ ಟೈಪ್ ಮಾಡಿದರೆ)gpt-4o-mini (ವೇಗ ಮತ್ತು ಕಡಿಮೆ ಬೆಲೆ)

Groq

ಅತ್ಯಂತ ವೇಗದ ಉತ್ತರಗಳು, ಉದಾರ ಫ್ರೀ ಟಯರ್, ಚಿಕ್ಕ ಮಾಡೆಲ್ ಆಯ್ಕೆ.

  1. console.groq.com ಗೆ ಹೋಗಿ Google ಅಥವಾ GitHub ಮೂಲಕ ಸೈನ್ ಇನ್ ಮಾಡಿ.
  2. API Keys → Create API Key, ಇದಕ್ಕೆ ಹೆಸರಿಡಿ, ಇದನ್ನು ಕಾಪಿ ಮಾಡಿ.
ಬೇಸ್ ವಿಳಾಸhttps://api.groq.com/openai/v1
ಪ್ರಯತ್ನಿಸಲು ಮಾಡೆಲ್ (ಕೈಯಿಂದ ಟೈಪ್ ಮಾಡಿದರೆ)llama-3.3-70b-versatile

Together AI

ಓಪನ್-ಸೋರ್ಸ್ ಮಾಡೆಲ್‌ಗಳ ವಿಶಾಲ ಆಯ್ಕೆ, ಪ್ರಾರಂಭಿಸಲು ಒಂದು ಸಣ್ಣ ಫ್ರೀ ಕ್ರೆಡಿಟ್ ಜೊತೆ ಪೇ-ಆಸ್-ಯು-ಗೋ.

  1. api.together.ai ಗೆ ಹೋಗಿ ಸೈನ್ ಅಪ್ ಮಾಡಿ.
  2. Settings → API Keys, ಡಿಫಾಲ್ಟ್ key ಕಾಪಿ ಮಾಡಿ ಅಥವಾ ಹೊಸದನ್ನು ಸೃಷ್ಟಿಸಿ.
ಬೇಸ್ ವಿಳಾಸhttps://api.together.xyz/v1
ಪ್ರಯತ್ನಿಸಲು ಮಾಡೆಲ್ (ಕೈಯಿಂದ ಟೈಪ್ ಮಾಡಿದರೆ)meta-llama/Llama-3.3-70B-Instruct-Turbo

Mistral

ಫ್ರೆಂಚ್ AI ಲ್ಯಾಬ್, ತಮ್ಮ ಸ್ವಂತ ಫ್ರಾಂಟಿಯರ್ ಮಾಡೆಲ್‌ಗಳು, ಹಗುರ ವೈಯಕ್ತಿಕ ಬಳಕೆಗಾಗಿ ಒಂದು ಫ್ರೀ ಟಯರ್.

  1. console.mistral.ai ಗೆ ಹೋಗಿ ಒಂದು ಖಾತೆ ಸೃಷ್ಟಿಸಿ.
  2. API Keys → Create new key, ಇದನ್ನು ಕಾಪಿ ಮಾಡಿ.
ಬೇಸ್ ವಿಳಾಸhttps://api.mistral.ai/v1
ಪ್ರಯತ್ನಿಸಲು ಮಾಡೆಲ್ (ಕೈಯಿಂದ ಟೈಪ್ ಮಾಡಿದರೆ)mistral-small-latest

OpenRouter

ಒಂದು key, ಒಂದು ಬಿಲ್, ಒಂದೇ ವಿಳಾಸದ ಮೂಲಕ ಹಲವಾರು ಇತರ ಕಂಪನಿಗಳ ಮಾಡೆಲ್‌ಗಳಿಗೆ (ಹಲವಾರು ಫ್ರೀ ಆಗಿರುವುದೂ ಸೇರಿ) ಪ್ರವೇಶ — ಬೇರೆ-ಬೇರೆ ಖಾತೆಗಳಲ್ಲಿ ಹೆಣಗಾಡುವ ಬದಲು ಹಲವಾರನ್ನು ಪ್ರಯತ್ನಿಸಲು ಇಚ್ಛಿಸುವುದಾದರೆ ಇದು ಒಂದು ಒಳ್ಳೆಯ ಆಯ್ಕೆ.

  1. openrouter.ai ಗೆ ಹೋಗಿ ಸೈನ್ ಇನ್ ಮಾಡಿ.
  2. Keys → Create Key, ಇದನ್ನು ಕಾಪಿ ಮಾಡಿ.
ಬೇಸ್ ವಿಳಾಸhttps://openrouter.ai/api/v1
ಪ್ರಯತ್ನಿಸಲು ಮಾಡೆಲ್ (ಕೈಯಿಂದ ಟೈಪ್ ಮಾಡಿದರೆ)meta-llama/llama-3.3-70b-instruct (ಅಥವಾ ಒಂದು ಫ್ರೀ ಆಯ್ಕೆಗಾಗಿ :free ಸೇರಿಸಿ)

Google Gemini

Google ದ ಸ್ವಂತ ಮಾಡೆಲ್‌ಗಳು, ಅವುಗಳ OpenAI-ಕಂಪ್ಯಾಟಿಬಲ್ ವಿಳಾಸದ ಮೂಲಕ ತಲುಪಬಹುದಾಗಿದೆ.

  1. aistudio.google.com/apikey ಗೆ ಹೋಗಿ ಒಂದು Google ಖಾತೆಯಿಂದ ಸೈನ್ ಇನ್ ಮಾಡಿ.
  2. Create API key, ಇದನ್ನು ಕಾಪಿ ಮಾಡಿ.
ಬೇಸ್ ವಿಳಾಸhttps://generativelanguage.googleapis.com/v1beta/openai
ಪ್ರಯತ್ನಿಸಲು ಮಾಡೆಲ್ (ಕೈಯಿಂದ ಟೈಪ್ ಮಾಡಿದರೆ)gemini-3.8-flash — ಆದರೆ Google ಇವುಗಳನ್ನು ಬೇರೆಯವುಗಳಿಗಿಂತ ವೇಗವಾಗಿ ಹೆಸರು ಬದಲಿಸುತ್ತದೆ/ನಿಲ್ಲಿಸುತ್ತದೆ, ಹಾಗಾಗಿ ಇಲ್ಲಿ ಲಭ್ಯ ಮಾದರಿಗಳನ್ನು ನೋಡಿ ಬಳಸುವುದು ವಿಶೇಷವಾಗಿ ಯೋಗ್ಯ

2. ಇದನ್ನು KattuOna ನಲ್ಲಿ ದಾಖಲಿಸುವುದು

KattuOna → Settings → AI ಎಂಜಿನ್ → API key ಬಳಸಿ ತೆರೆಯಿರಿ, ನಂತರ ಭರ್ತಿ ಮಾಡಿ:

  • ಬೇಸ್ ವಿಳಾಸ — ನೀವು ಆಯ್ಕೆ ಮಾಡಿದ ಪ್ರೊವೈಡರ್‌ಗಾಗಿ ಮೇಲಿನ ಟೇಬಲ್‌ನಿಂದ ನಿಖರ ವಿಳಾಸ.
  • API key — ನೀವು ಈಗ ಕಾಪಿ ಮಾಡಿದ key.
  • ಮಾದರಿ — ಮೇಲಿನ ವಿಳಾಸ ಮತ್ತು key ಭರ್ತಿ ಮಾಡಿದ ನಂತರ ಲಭ್ಯ ಮಾದರಿಗಳನ್ನು ನೋಡಿ ಟ್ಯಾಪ್ ಮಾಡಿ, ಮತ್ತು KattuOna ಪ್ರೊವೈಡರ್‌ನಿಂದ ಹಿಂತಿರುಗಿಸುವ ಲೈವ್ ಪಟ್ಟಿಯಿಂದ ಒಂದನ್ನು ಆಯ್ಕೆ ಮಾಡಿ. ಇದು ಈ ಫೀಲ್ಡ್ ಅನ್ನು ಭರ್ತಿ ಮಾಡುವ ಭರವಸೆಯುಳ್ಳ ವಿಧಾನ, ಏಕೆಂದರೆ ಇದು ಯಾವಾಗಲೂ ಆ ಪ್ರೊವೈಡರ್ ಇಂದು ನಿಮ್ಮ key ಗೆ ಏನು ಕೊಡುತ್ತದೆ ಎಂಬುದನ್ನೇ ಪ್ರತಿಬಿಂಬಿಸುತ್ತದೆ — ಹಳೆಯದಾಗಬಹುದಾದ ಒಂದು ಪೇಜ್‌ನಲ್ಲಿ ಮುದ್ರಿಸಲಾದ ಹೆಸರು ಅಲ್ಲ.

ಉಳಿಸಿ ಮತ್ತು ಪರೀಕ್ಷಿಸಿ ಟ್ಯಾಪ್ ಮಾಡಿ — KattuOna ಒಂದು ಸಣ್ಣ ಟೆಸ್ಟ್ ಮೆಸೇಜ್ ಕಳುಹಿಸುತ್ತದೆ ಮತ್ತು key, ವಿಳಾಸ, ಅಥವಾ ಮಾದರಿ ತಪ್ಪಾಗಿದೆಯೇ ಎಂದು ಕೂಡಲೇ ಹೇಳುತ್ತದೆ.

ಖರ್ಚು: ಮೇಲಿನ ಪ್ರತಿ ಪ್ರೊವೈಡರ್ ನಿಮ್ಮ ಸ್ವಂತ ಬಳಕೆಯ ಆಧಾರದ ಮೇಲೆ ಬಿಲ್ ಮಾಡುತ್ತದೆ (ಅಥವಾ ರೇಟ್-ಲಿಮಿಟ್ ಮಾಡುತ್ತದೆ). KattuOna ದ ಡೆವಲಪರ್‌ಗೆ ನಿಮಗೆ ಏನು ಚಾರ್ಜ್ ಆಗುತ್ತಿದೆ ಎಂಬುದರ ಬಗ್ಗೆ ಯಾವುದೇ ದೃಷ್ಟಿಕೋನ ಅಥವಾ ನಿಯಂತ್ರಣ ಇಲ್ಲ — ಪ್ರಾರಂಭಿಸುವ ಮೊದಲು ಪ್ರತಿ ಪ್ರೊವೈಡರ್‌ನ ಸ್ವಂತ ಬೆಲೆ ಪೇಜ್ ನೋಡಿ, ಮತ್ತು ಬೆಲೆ-ಜಾಗೃತರಾಗಿದ್ದರೆ ಬಳಕೆಯ ಮೇಲೆ ಗಮನವಿಡಿ.
