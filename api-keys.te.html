KattuOna కోసం ఒక API key పొందండి

తమ స్వంత సర్వర్‌ను నడపడానికి లేదా KattuOna యొక్క బిల్ట్-ఇన్ దానిని ఉపయోగించడానికి బదులుగా, AI కోసం ఒక కంపెనీకి నేరుగా చెల్లించాలని కోరుకునే వారి కోసం.

KattuOna యొక్క "API key ఉపయోగించండి" ఆప్షన్ సాధారణ OpenAI చాట్ ఫార్మాట్‌ను మాట్లాడే ఏ కంపెనీతోనైనా పని చేస్తుంది — ఇది, ఈ రోజుల్లో, వాటిలో ఎక్కువ భాగం. దిగువ నుండి ఒకదాన్ని ఎంచుకోండి, సైన్ అప్ చేయండి, ఒక key సృష్టించండి, మరియు దానిని (ఆ ప్రొవైడర్ యొక్క బేస్ అడ్రస్‌తో పాటు) KattuOna → Settings → AI ఇంజన్ → API key ఉపయోగించండిలో పేస్ట్ చేయండి.

మీ key మీ ఫోన్‌లో మాత్రమే సేవ్ చేయబడుతుంది. KattuOna దానిని మీరు ఎంచుకున్న కంపెనీకి నేరుగా పంపుతుంది, ఏ యాప్ అయినా చేసే విధంగానే — KattuOna యొక్క డెవలపర్ దానిని లేదా దానిని ఉపయోగించే సంభాషణలను ఎప్పుడూ చూడదు.

మోడల్ పేర్ల గురించి: దిగువ ఉన్న ప్రతి కంపెనీ కాలానుగుణంగా పాత మోడళ్లను తీసివేసి కొత్తవాటిని జోడిస్తుంది, కాబట్టి ఈ పేజీపై ప్రింట్ చేయబడిన ఒక మోడల్ పేరు తర్వాత పని చేయడం ఆపవచ్చు (ఈ పేజీ యొక్క ఒక ముందటి వెర్షన్‌తో ఇది జరిగింది, అందులో Google తర్వాత తీసివేసిన ఒక Gemini మోడల్ పేరు జాబితా చేయబడింది). KattuOnaలో మీ బేస్ అడ్రస్ మరియు key ఎంటర్ చేసిన తర్వాత, అక్కడే Settings → AI ఇంజన్‌లో అందుబాటులో ఉన్న మోడల్స్‌ను చూడండిను నొక్కండి — KattuOna నేరుగా ప్రొవైడర్‌ను, ఆ క్షణంలోనే, మీ key కోసం ఈరోజు ఏ మోడళ్లు పని చేస్తాయో అడుగుతుంది, మరియు కాలం చెల్లిన పేరును టైప్ చేయడానికి బదులుగా వాటిలో ఒకదానిపై మీరు నొక్కేలా చేస్తుంది. దిగువ ఇచ్చిన మోడల్ పేర్లు మీరు స్వయంగా ఒక పేరును టైప్ చేయాలని కోరుకుంటే కేవలం ఒక ప్రారంభ బిందువు మాత్రమే.

1. ఒక ప్రొవైడర్‌ను ఎంచుకుని ఒక key పొందండి

OpenAI

ChatGPT వెనుక ఉన్న కంపెనీ. నమ్మకమైనది, విస్తృతంగా ఉపయోగించబడుతుంది, వాడకం ఆధారంగా ధరలు.

  1. platform.openai.comకు వెళ్లి ఒక ఖాతాను సృష్టించండి.
  2. Billing క్రింద ఒక పేమెంట్ పద్ధతిని జోడించండి (API వాడకం మీకు ఉన్న ఏదైనా ChatGPT సబ్‌స్క్రిప్షన్ నుండి వేరుగా ఉంటుంది).
  3. API keysకు వెళ్లి, Create new secret keyపై క్లిక్ చేసి, వెంటనే దానిని కాపీ చేయండి — ఇది ఒక్కసారి మాత్రమే చూపబడుతుంది.
బేస్ అడ్రస్https://api.openai.com/v1
ప్రయత్నించడానికి ఒక మోడల్ (మీరే చేతితో టైప్ చేస్తే)gpt-4o-mini (వేగంగా మరియు చౌకగా)

Groq

అత్యంత వేగవంతమైన సమాధానాలు, ఉదారమైన ఫ్రీ టైర్, తక్కువ మోడల్ ఎంపిక.

  1. console.groq.comకు వెళ్లి Google లేదా GitHubతో సైన్ ఇన్ చేయండి.
  2. API Keys → Create API Key, దానికి పేరు పెట్టి, దానిని కాపీ చేయండి.
బేస్ అడ్రస్https://api.groq.com/openai/v1
ప్రయత్నించడానికి ఒక మోడల్ (మీరే చేతితో టైప్ చేస్తే)llama-3.3-70b-versatile

Together AI

ఓపెన్-సోర్స్ మోడళ్ల విస్తృత ఎంపిక, ప్రారంభంలో ఒక చిన్న ఫ్రీ క్రెడిట్‌తో పే-యాజ్-యు-గో.

  1. api.together.aiకు వెళ్లి సైన్ అప్ చేయండి.
  2. Settings → API Keys, డిఫాల్ట్ keyను కాపీ చేయండి లేదా ఒక కొత్తదాన్ని సృష్టించండి.

Mistral

ఫ్రెంచ్ AI లాబ్, వారి స్వంత ఫ్రాంటియర్ మోడళ్లు, తక్కువ వ్యక్తిగత వాడకం కోసం ఒక ఫ్రీ టైర్.

  1. console.mistral.aiకు వెళ్లి ఒక ఖాతాను సృష్టించండి.

OpenRouter

ఒక key, ఒక బిల్, ఒకే అడ్రస్ ద్వారా డజన్ల కొద్దీ ఇతర కంపెనీల మోడళ్లకు (అనేక ఫ్రీ వాటితో సహా) యాక్సెస్ — వేర్వేరు ఖాతాలతో తలనొప్పి పెట్టుకోకుండా చాలా వాటిని ప్రయత్నించాలనుకుంటే ఇది ఒక మంచి ఎంపిక.

  1. openrouter.aiకు వెళ్లి సైన్ ఇన్ చేయండి.
  2. Keys → Create Key, దానిని కాపీ చేయండి.

Google Gemini

  1. aistudio.google.com/apikeyకు వెళ్లి ఒక Google ఖాతాతో సైన్ ఇన్ చేయండి.
  2. Create API key, దానిని కాపీ చేయండి.

2. దీనిని KattuOnaలో ఎంటర్ చేయడం

KattuOna → Settings → AI ఇంజన్ → API key ఉపయోగించండిను తెరిచి, తర్వాత ఇవి ఫిల్ చేయండి:

  • బేస్ అడ్రస్ — మీరు ఎంచుకున్న ప్రొవైడర్ కోసం పై పట్టిక నుండి ఖచ్చితమైన అడ్రస్.
  • API key — మీరు ఇప్పుడే కాపీ చేసిన key.
  • మోడల్ — పై అడ్రస్ మరియు key ఫిల్ చేసిన తర్వాత అందుబాటులో ఉన్న మోడల్స్‌ను చూడండిను నొక్కండి, మరియు KattuOna ప్రొవైడర్ నుండి తిరిగి పొందే లైవ్ జాబితా నుండి ఒకదాన్ని ఎంచుకోండి. ఇది ఈ ఫీల్డ్‌ను ఫిల్ చేయడానికి నమ్మకమైన మార్గం, ఎందుకంటే ఇది ఎల్లప్పుడూ ఆ ప్రొవైడర్ మీ key కోసం ఇప్పుడు ఏమి అందిస్తుందో ప్రతిబింబిస్తుంది — పాతదవగలిగే ఒక పేజీపై ప్రింట్ చేయబడిన పేరు కాదు.

సేవ్ చేసి టెస్ట్ చేయండిను నొక్కండి — KattuOna ఒక చిన్న టెస్ట్ మెసేజ్‌ను పంపుతుంది మరియు key, అడ్రస్, లేదా మోడల్ తప్పుగా ఉంటే వెంటనే మీకు తెలియజేస్తుంది.

ఖర్చులు: పై ఇచ్చిన ప్రతి ప్రొవైడర్ మీ స్వంత వాడకం ఆధారంగా బిల్ చేస్తుంది (లేదా రేట్-లిమిట్ చేస్తుంది). మీకు ఏమి చార్జ్ చేయబడుతుందో KattuOna యొక్క డెవలపర్‌కు ఎలాంటి దృశ్యమానత లేదా నియంత్రణ లేదు — ప్రారంభించే ముందు ప్రతి ప్రొవైడర్ యొక్క స్వంత ప్రైసింగ్ పేజీని చూడండి, మరియు మీరు ఖర్చు పట్ల జాగ్రత్తగా ఉంటే వాడకంపై ఒక కన్ను ఉంచండి.
