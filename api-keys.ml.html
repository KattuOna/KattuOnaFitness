KattuOna-ക്കുള്ള API key നേടുക

സ്വന്തം സെർവർ ഓടിക്കുന്നതിനോ KattuOna-യുടെ ബിൽറ്റ്-ഇൻ AI ഉപയോഗിക്കുന്നതിനോ പകരം, AI-ക്ക് ഒരു കമ്പനിക്ക് നേരിട്ട് പണം നൽകാൻ ഇഷ്ടപ്പെടുന്നവർക്കായി.

KattuOna-യുടെ "API key ഉപയോഗിക്കുക" ഓപ്ഷൻ സാധാരണ OpenAI ചാറ്റ് ഫോർമാറ്റ് സംസാരിക്കുന്ന ഏതെങ്കിലും കമ്പനിയുമായും പ്രവർത്തിക്കുന്നു — ഇന്ന് ഇതിൽ അധികവും ഇതുതന്നെ ചെയ്യുന്നു. താഴെ നിന്ന് ഒന്ന് തിരഞ്ഞെടുക്കുക, സൈൻ അപ്പ് ചെയ്യുക, ഒരു key ഉണ്ടാക്കുക, അത് (ആ പ്രൊവൈഡറുടെ ബേസ് അഡ്രസോടൊപ്പം) KattuOna → Settings → AI എഞ്ചിൻ → ഒരു API key ഉപയോഗിക്കുക-ൽ പേസ്റ്റ് ചെയ്യുക.

നിങ്ങളുടെ key നിങ്ങളുടെ ഫോണിൽ മാത്രം സേവ് ആകുന്നു. നിങ്ങൾ തിരഞ്ഞെടുത്ത കമ്പനിക്ക് നേരെ KattuOna ഇത് അയയ്ക്കുന്നു, ഏത് ആപ്പും ചെയ്യുന്നതുപോലെ തന്നെ — KattuOna-യുടെ ഡെവലപ്പർ ഇതോ ഇത് ഉപയോഗിക്കുന്ന സംഭാഷണങ്ങളോ ഒരിക്കലും കാണുന്നില്ല.

മോഡൽ പേരുകളെക്കുറിച്ച്: താഴെയുള്ള ഓരോ കമ്പനിയും കാലക്രമത്തിൽ പഴയ മോഡലുകൾ പിൻവലിക്കുകയും പുതിയവ ചേർക്കുകയും ചെയ്യുന്നു, അതിനാൽ ഈ പേജിൽ അടിച്ചിരിക്കുന്ന ഒരു മോഡൽ പേര് പിന്നീട് പ്രവർത്തിക്കാതെ വന്നേക്കാം (ഈ പേജിന്റെ ഒരു മുൻ പതിപ്പിൽ ഇത് സംഭവിച്ചിരുന്നു, അതിൽ Google പിന്നീട് നീക്കം ചെയ്ത ഒരു Gemini മോഡൽ ലിസ്റ്റ് ചെയ്തിരുന്നു). KattuOna-യിൽ നിങ്ങളുടെ ബേസ് അഡ്രസും key-യും നൽകിയ ശേഷം, അവിടെ തന്നെ Settings → AI എഞ്ചിൻ-ൽ ലഭ്യമായ മോഡലുകൾ കാണുക ടാപ്പ് ചെയ്യുക — KattuOna നേരിട്ട് പ്രൊവൈഡറോട്, ആ നിമിഷം തന്നെ, ഇന്ന് നിങ്ങളുടെ key-ക്ക് ഏത് മോഡലുകൾ പ്രവർത്തിക്കുമെന്ന് ചോദിക്കുന്നു, പഴകിയേക്കാവുന്ന ഒരു പേര് ടൈപ്പ് ചെയ്യുന്നതിന് പകരം ഒന്നിൽ ടാപ്പ് ചെയ്യാൻ അനുവദിക്കുന്നു. താഴെയുള്ള മോഡൽ പേരുകൾ, നിങ്ങൾ സ്വയം ഒരു പേര് ടൈപ്പ് ചെയ്യാൻ ആഗ്രഹിക്കുന്നെങ്കിൽ, ഒരു തുടക്ക പോയിന്റ് മാത്രമാണ്.

1. ഒരു പ്രൊവൈഡർ തിരഞ്ഞെടുത്ത് ഒരു key നേടുക

OpenAI

ChatGPT-ക്ക് പിന്നിലെ കമ്പനി. വിശ്വസനീയം, വ്യാപകമായി ഉപയോഗിക്കുന്നത്, ഉപയോഗത്തിന് അനുസരിച്ചുള്ള വില.

  1. platform.openai.com-ൽ പോയി ഒരു അക്കൗണ്ട് ഉണ്ടാക്കുക.
  2. Billing-ൽ ഒരു പേയ്‌മെന്റ് രീതി ചേർക്കുക (API ഉപയോഗം നിങ്ങൾക്ക് ഉണ്ടായേക്കാവുന്ന ഏതെങ്കിലും ChatGPT സബ്സ്ക്രിപ്ഷനിൽ നിന്ന് വേറെയാണ്).
  3. API keys-ൽ പോയി, Create new secret key ക്ലിക്ക് ചെയ്യുക, ഉടൻ അത് കോപ്പി ചെയ്യുക — ഇത് ഒരു തവണ മാത്രമേ കാണിക്കുന്നുള്ളൂ.
ബേസ് അഡ്രസ്https://api.openai.com/v1
പരീക്ഷിക്കാവുന്ന മോഡൽ (കൈ കൊണ്ട് ടൈപ്പ് ചെയ്യുകയാണെങ്കിൽ)gpt-4o-mini (വേഗതയുള്ളതും വിലക്കുറവുള്ളതും)

Groq

അതിവേഗ ഉത്തരങ്ങൾ, ഉദാരമായ ഫ്രീ ടയർ, കുറച്ച് മോഡൽ തിരഞ്ഞെടുപ്പുകൾ.

  1. console.groq.com-ൽ പോയി Google അല്ലെങ്കിൽ GitHub ഉപയോഗിച്ച് സൈൻ ഇൻ ചെയ്യുക.
  2. API Keys → Create API Key, ഇതിന് പേര് നൽകുക, കോപ്പി ചെയ്യുക.
ബേസ് അഡ്രസ്https://api.groq.com/openai/v1
പരീക്ഷിക്കാവുന്ന മോഡൽ (കൈ കൊണ്ട് ടൈപ്പ് ചെയ്യുകയാണെങ്കിൽ)llama-3.3-70b-versatile

Together AI

ഓപ്പൺ-സോഴ്സ് മോഡലുകളുടെ വിശാലമായ തിരഞ്ഞെടുപ്പ്, തുടക്കത്തിൽ ചെറിയ ഫ്രീ ക്രെഡിറ്റോടെ പേ-ആസ്-യു-ഗോ.

  1. api.together.ai-ൽ പോയി സൈൻ അപ്പ് ചെയ്യുക.
  2. Settings → API Keys, ഡിഫാൾട്ട് key കോപ്പി ചെയ്യുക അല്ലെങ്കിൽ ഒരു പുതിയത് ഉണ്ടാക്കുക.
ബേസ് അഡ്രസ്https://api.together.xyz/v1
പരീക്ഷിക്കാവുന്ന മോഡൽ (കൈ കൊണ്ട് ടൈപ്പ് ചെയ്യുകയാണെങ്കിൽ)meta-llama/Llama-3.3-70B-Instruct-Turbo

Mistral

  1. console.mistral.ai-ൽ പോയി ഒരു അക്കൗണ്ട് ഉണ്ടാക്കുക.
  2. API Keys → Create new key, കോപ്പി ചെയ്യുക.
ബേസ് അഡ്രസ്https://api.mistral.ai/v1
പരീക്ഷിക്കാവുന്ന മോഡൽ (കൈ കൊണ്ട് ടൈപ്പ് ചെയ്യുകയാണെങ്കിൽ)mistral-small-latest

OpenRouter

ഒരു key, ഒരു ബിൽ, ഒരേ ഒരു അഡ്രസ് വഴി മറ്റ് ഡസൻ കണക്കിന് കമ്പനികളുടെ മോഡലുകളിലേക്കും (ഫ്രീ ആയവ ഉൾപ്പെടെ) ആക്സസ് — വെവ്വേറെ അക്കൗണ്ടുകളുമായി മല്ലിടുന്നതിന് പകരം പലതും പരീക്ഷിക്കാൻ ആഗ്രഹിക്കുന്നെങ്കിൽ ഇതൊരു നല്ല തിരഞ്ഞെടുപ്പാണ്.

  1. openrouter.ai-ൽ പോയി സൈൻ ഇൻ ചെയ്യുക.
  2. Keys → Create Key, കോപ്പി ചെയ്യുക.
ബേസ് അഡ്രസ്https://openrouter.ai/api/v1
പരീക്ഷിക്കാവുന്ന മോഡൽ (കൈ കൊണ്ട് ടൈപ്പ് ചെയ്യുകയാണെങ്കിൽ)meta-llama/llama-3.3-70b-instruct (അല്ലെങ്കിൽ ഒരു ഫ്രീ ഓപ്ഷനായി :free ചേർക്കുക)

Google Gemini

Google-ന്റെ തന്നെ മോഡലുകൾ, അവരുടെ OpenAI-കോംപാറ്റിബിൾ അഡ്രസ് വഴി എത്തിച്ചേരാം.

  1. aistudio.google.com/apikey-ൽ പോയി ഒരു Google അക്കൗണ്ട് ഉപയോഗിച്ച് സൈൻ ഇൻ ചെയ്യുക.
  2. Create API key, കോപ്പി ചെയ്യുക.
ബേസ് അഡ്രസ്https://generativelanguage.googleapis.com/v1beta/openai
പരീക്ഷിക്കാവുന്ന മോഡൽ (കൈ കൊണ്ട് ടൈപ്പ് ചെയ്യുകയാണെങ്കിൽ)gemini-3.8-flash — പക്ഷേ Google ഇവയെ മറ്റുള്ളവയേക്കാൾ വേഗത്തിൽ പേര് മാറ്റുന്നു/പിൻവലിക്കുന്നു, അതിനാൽ ഇവിടെ ലഭ്യമായ മോഡലുകൾ കാണുക ഉപയോഗിക്കുന്നത് പ്രത്യേകിച്ച് ഫലപ്രദമാണ്

2. ഇത് KattuOna-യിൽ നൽകുന്നത്

KattuOna → Settings → AI എഞ്ചിൻ → ഒരു API key ഉപയോഗിക്കുക തുറക്കുക, എന്നിട്ട് പൂരിപ്പിക്കുക:

  • ബേസ് അഡ്രസ് — നിങ്ങൾ തിരഞ്ഞെടുത്ത പ്രൊവൈഡറിനായി മുകളിലെ ടേബിളിൽ ഉള്ള അതേ കൃത്യമായ അഡ്രസ്.
  • API key — ഇപ്പോൾ നിങ്ങൾ കോപ്പി ചെയ്ത key.
  • മോഡൽ — മുകളിലെ അഡ്രസും key-യും പൂരിപ്പിച്ച ശേഷം ലഭ്യമായ മോഡലുകൾ കാണുക ടാപ്പ് ചെയ്യുക, പ്രൊവൈഡറിൽ നിന്ന് KattuOna-ക്ക് തിരിച്ചു ലഭിക്കുന്ന ലൈവ് ലിസ്റ്റിൽ നിന്ന് ഒന്ന് തിരഞ്ഞെടുക്കുക. ഇത് ഈ ഫീൽഡ് പൂരിപ്പിക്കാനുള്ള വിശ്വസനീയമായ രീതിയാണ്, കാരണം അത് എപ്പോഴും ആ പ്രൊവൈഡർ നിങ്ങളുടെ key-ക്ക് ഇപ്പോൾ നൽകുന്നത് പ്രതിഫലിപ്പിക്കുന്നു — പഴകിപ്പോയേക്കാവുന്ന, ഒരു പേജിൽ അടിച്ച പേരല്ല.

സേവ് ചെയ്ത് ടെസ്റ്റ് ചെയ്യുക ടാപ്പ് ചെയ്യുക — KattuOna ഒരു ചെറിയ ടെസ്റ്റ് മെസ്സേജ് അയച്ച്, key, അഡ്രസ്, അല്ലെങ്കിൽ മോഡൽ തെറ്റാണോ എന്ന് ഉടൻ പറയും.

ചെലവ്: മുകളിലെ ഓരോ പ്രൊവൈഡറും നിങ്ങളുടെ തന്നെ ഉപയോഗത്തിന്റെ അടിസ്ഥാനത്തിൽ ബിൽ ചെയ്യുന്നു (അല്ലെങ്കിൽ റേറ്റ്-ലിമിറ്റ് ചെയ്യുന്നു). നിങ്ങളിൽ നിന്ന് എന്ത് ചാർജ് ചെയ്യുന്നു എന്നതിൽ KattuOna-യുടെ ഡെവലപ്പർക്ക് കാഴ്ചയോ നിയന്ത്രണമോ ഇല്ല — തുടങ്ങുന്നതിന് മുൻപ് ഓരോ പ്രൊവൈഡറുടെയും സ്വന്തം പ്രൈസിംഗ് പേജ് പരിശോധിക്കുക, ചെലവിനെക്കുറിച്ച് ബോധമുള്ളവരാണെങ്കിൽ ഉപയോഗത്തിൽ കണ്ണ് വെക്കുക.
