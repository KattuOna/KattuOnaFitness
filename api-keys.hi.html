KattuOna के लिए API key पाएँ

उन लोगों के लिए जो अपना सर्वर चलाने या KattuOna के बिल्ट-इन AI के बजाय, किसी कंपनी को AI के लिए सीधे पैसे देना पसंद करते हैं।

KattuOna का "API key इस्तेमाल करें" विकल्प किसी भी ऐसी कंपनी के साथ काम करता है जिसका API सामान्य OpenAI चैट फ़ॉर्मेट बोलता है — जो, आज के समय में, इनमें से ज़्यादातर करती हैं। नीचे से एक चुनें, साइन अप करें, एक key बनाएँ, और उसे (उस प्रोवाइडर के बेस अड्रेस के साथ) KattuOna → Settings → AI इंजन → API key इस्तेमाल करें में पेस्ट करें।

आपकी key सिर्फ़ आपके फ़ोन पर सेव होती है। KattuOna इसे सीधे उस कंपनी को भेजता है जो आपने चुनी है, ठीक वैसे ही जैसे कोई भी ऐप करता है — KattuOna का डेवलपर इसे या इसका उपयोग करने वाली बातचीत को कभी नहीं देखता।

मॉडल के नामों के बारे में: नीचे दी गई हर कंपनी समय-समय पर पुराने मॉडल हटाती है और नए जोड़ती है, इसलिए इस पेज पर लिखा कोई मॉडल नाम आगे चल कर काम करना बंद कर सकता है (ऐसा इस पेज के एक पहले वर्शन के साथ हुआ था, जिसमें एक Gemini मॉडल का नाम था जिसे Google ने बाद में हटा दिया)। KattuOna में अपना बेस अड्रेस और key दर्ज करने के बाद, वहीं Settings → AI इंजन में उपलब्ध मॉडल देखें पर टैप करें — KattuOna सीधे प्रोवाइडर से, उसी समय, पूछता है कि आज आपकी key के लिए कौन-से मॉडल काम करते हैं, और आपको कोई पुराना हो सकने वाला नाम टाइप करने के बजाय किसी एक पर टैप करने देता है। नीचे दिए मॉडल नाम केवल एक शुरुआती बिंदु हैं, अगर आप खुद कोई नाम टाइप करना पसंद करें।

1. एक प्रोवाइडर चुनें और एक key पाएँ

OpenAI

ChatGPT के पीछे की कंपनी। भरोसेमंद, व्यापक रूप से इस्तेमाल होने वाली, उपयोग के आधार पर कीमत।

  1. platform.openai.com पर जाएँ और एक खाता बनाएँ।
  2. Billing में एक पेमेंट तरीका जोड़ें (API का उपयोग आपकी किसी भी ChatGPT सब्सक्रिप्शन से अलग है)।
  3. API keys पर जाएँ, Create new secret key पर क्लिक करें, और उसे तुरंत कॉपी कर लें — यह केवल एक बार दिखाई जाती है।
बेस अड्रेसhttps://api.openai.com/v1
आज़माने के लिए मॉडल (यदि हाथ से टाइप करें)gpt-4o-mini (तेज़ और सस्ता)

Groq

बहुत तेज़ जवाब, उदार फ़्री टियर, थोड़े कम मॉडल विकल्प।

  1. console.groq.com पर जाएँ और Google या GitHub से साइन इन करें।
  2. API Keys → Create API Key, इसे नाम दें, इसे कॉपी करें।
बेस अड्रेसhttps://api.groq.com/openai/v1
आज़माने के लिए मॉडल (यदि हाथ से टाइप करें)llama-3.3-70b-versatile

Together AI

ओपन-सोर्स मॉडलों का विस्तृत चुनाव, शुरुआत में थोड़े फ़्री क्रेडिट के साथ पे-ऐज़-यू-गो।

  1. api.together.ai पर जाएँ और साइन अप करें।
  2. Settings → API Keys, डिफ़ॉल्ट key कॉपी करें या एक नई बनाएँ।
बेस अड्रेसhttps://api.together.xyz/v1
आज़माने के लिए मॉडल (यदि हाथ से टाइप करें)meta-llama/Llama-3.3-70B-Instruct-Turbo

Mistral

फ़्रेंच AI लैब, अपने ही फ्रंटियर मॉडल, हल्के व्यक्तिगत उपयोग के लिए एक फ़्री टियर।

  1. console.mistral.ai पर जाएँ और एक खाता बनाएँ।
  2. API Keys → Create new key, इसे कॉपी करें।
बेस अड्रेसhttps://api.mistral.ai/v1
आज़माने के लिए मॉडल (यदि हाथ से टाइप करें)mistral-small-latest

OpenRouter

एक key, एक बिल, एक ही अड्रेस के ज़रिए दर्जनों अन्य कंपनियों के मॉडलों (जिनमें कई फ़्री भी हैं) तक पहुँच — अलग-अलग खातों में उलझने के बजाय कई मॉडल आज़माना चाहें तो यह एक अच्छा विकल्प है।

  1. openrouter.ai पर जाएँ और साइन इन करें।
  2. Keys → Create Key, इसे कॉपी करें।
बेस अड्रेसhttps://openrouter.ai/api/v1
आज़माने के लिए मॉडल (यदि हाथ से टाइप करें)meta-llama/llama-3.3-70b-instruct (या मुफ़्त विकल्प के लिए :free जोड़ें)

Google Gemini

Google के अपने मॉडल, इनके OpenAI-कम्पैटिबल अड्रेस के ज़रिए पहुँचे जा सकते हैं।

  1. aistudio.google.com/apikey पर जाएँ और एक Google खाते से साइन इन करें।
  2. Create API key, इसे कॉपी करें।
बेस अड्रेसhttps://generativelanguage.googleapis.com/v1beta/openai
आज़माने के लिए मॉडल (यदि हाथ से टाइप करें)gemini-3.8-flash — लेकिन Google इन्हें बाकी से ज़्यादा तेज़ी से नाम बदलता/हटाता है, इसलिए यहाँ उपलब्ध मॉडल देखें का उपयोग करना ख़ास तौर पर फ़ायदेमंद है

2. इसे KattuOna में दर्ज करना

KattuOna → Settings → AI इंजन → API key इस्तेमाल करें खोलें, फिर भरें:

  • बेस अड्रेस — आपके चुने हुए प्रोवाइडर के लिए ऊपर दी गई टेबल से वही सटीक अड्रेस।
  • API key — जो key आपने अभी कॉपी की है।
  • मॉडल — ऊपर दिए अड्रेस और key भरने के बाद उपलब्ध मॉडल देखें पर टैप करें, और KattuOna को प्रोवाइडर से मिलने वाली लाइव सूची से एक चुनें। यह फ़ील्ड भरने का भरोसेमंद तरीका है, क्योंकि यह हमेशा यह दिखाता है कि वह प्रोवाइडर आपकी key के लिए अभी क्या देता है — किसी पेज पर लिखा कोई नाम नहीं, जो पुराना हो सकता है।

सेव करें और टेस्ट करें पर टैप करें — KattuOna एक छोटा टेस्ट मैसेज भेजता है और बताता है कि key, अड्रेस या मॉडल में कोई गड़बड़ है या नहीं।

लागत: ऊपर दिया हर प्रोवाइडर आपके अपने उपयोग के आधार पर बिल करता है (या रेट-लिमिट करता है)। KattuOna का डेवलपर यह नहीं देख सकता या नियंत्रित नहीं कर सकता कि आपसे क्या चार्ज किया जा रहा है — शुरू करने से पहले हर प्रोवाइडर का अपना प्राइसिंग पेज देखें, और कीमत के प्रति सचेत हैं तो उपयोग पर नज़र रखें।
