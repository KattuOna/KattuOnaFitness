KattuOna-র জন্য একটি API key নিন

যারা নিজের সার্ভার চালানো বা KattuOna-র বিল্ট-ইন সার্ভার ব্যবহার করার বদলে AI-র জন্য সরাসরি একটি কোম্পানিকে টাকা দিতে চান, তাদের জন্য।

KattuOna-র "API key ব্যবহার করুন" অপশন যে কোনো এমন কোম্পানির সাথে কাজ করে যার API সাধারণ OpenAI চ্যাট ফরম্যাটে কথা বলে — যা, আজকাল, তাদের বেশিরভাগই। নিচে থেকে একটি বেছে নিন, সাইন আপ করুন, একটি key তৈরি করুন, এবং এটি (সেই প্রোভাইডারের বেস অ্যাড্রেসের সাথে) KattuOna → Settings → AI ইঞ্জিন → API key ব্যবহার করুন-এ পেস্ট করুন।

আপনার key শুধু আপনার ফোনে সেভ থাকে। KattuOna এটি সরাসরি আপনি বেছে নেওয়া কোম্পানিকে পাঠায়, অন্য কোনো অ্যাপের মতোই — KattuOna-র ডেভেলপার কখনো এটি বা এটি ব্যবহার করা কথোপকথন দেখে না।

মডেলের নাম নিয়ে: নিচের প্রতিটি কোম্পানি সময়ের সাথে পুরোনো মডেল বাদ দেয় এবং নতুন মডেল যুক্ত করে, তাই এই পেজে লেখা একটি মডেলের নাম পরে কাজ করা বন্ধ করে দিতে পারে (এই পেজের একটি আগের ভার্সনে এমনই হয়েছিল, যেখানে একটি Gemini মডেলের নাম লেখা ছিল যা Google পরে সরিয়ে দিয়েছে)। KattuOna-এ আপনার বেস অ্যাড্রেস ও key টাইপ করার পর, সেখানেই Settings → AI ইঞ্জিন-এ উপলব্ধ মডেল দেখুন-এ ট্যাপ করুন — KattuOna সরাসরি প্রোভাইডারকে, ঠিক তখনই, জিজ্ঞাসা করে আজ আপনার key-র জন্য কোন মডেলগুলো কাজ করে, এবং পুরোনো হয়ে যেতে পারে এমন একটি নাম টাইপ করার বদলে আপনাকে একটিতে ট্যাপ করতে দেয়। নিচের মডেলের নামগুলো শুধু একটি শুরুর বিন্দু, যদি আপনি তার বদলে নিজে একটি টাইপ করতে চান।

1. একটি প্রোভাইডার বেছে নিন এবং একটি key নিন

OpenAI

ChatGPT-র পেছনের কোম্পানি। ভরসাযোগ্য, ব্যাপকভাবে ব্যবহৃত, ব্যবহার-ভিত্তিক প্রাইসিং।

  1. platform.openai.com-এ যান এবং একটি অ্যাকাউন্ট তৈরি করুন।
  2. Billing-এর অধীনে একটি পেমেন্ট পদ্ধতি যুক্ত করুন (API ব্যবহার আপনার থাকা কোনো ChatGPT সাবস্ক্রিপশন থেকে আলাদা)।
  3. API keys-এ যান, Create new secret key-এ ক্লিক করুন, এবং এটি তখনই কপি করুন — এটি শুধু একবারই দেখানো হয়।
বেস অ্যাড্রেসhttps://api.openai.com/v1
চেষ্টা করার জন্য মডেল (হাতে টাইপ করলে)gpt-4o-mini (দ্রুত এবং সস্তা)

Groq

খুব দ্রুত উত্তর, উদার ফ্রি টিয়ার, কম মডেল অপশন।

  1. console.groq.com-এ যান এবং Google বা GitHub দিয়ে সাইন ইন করুন।
  2. API Keys → Create API Key, এর একটি নাম দিন, কপি করুন।
বেস অ্যাড্রেসhttps://api.groq.com/openai/v1
চেষ্টা করার জন্য মডেল (হাতে টাইপ করলে)llama-3.3-70b-versatile

Together AI

ওপেন-সোর্স মডেলের বিস্তৃত পছন্দ, শুরুতে একটু ফ্রি ক্রেডিট সহ পে-অ্যাজ-ইউ-গো।

  1. api.together.ai-এ যান এবং সাইন আপ করুন।
  2. Settings → API Keys, ডিফল্ট key কপি করুন বা একটি নতুন তৈরি করুন।
বেস অ্যাড্রেসhttps://api.together.xyz/v1
চেষ্টা করার জন্য মডেল (হাতে টাইপ করলে)meta-llama/Llama-3.3-70B-Instruct-Turbo

Mistral

ফ্রেঞ্চ AI ল্যাব, তাদের নিজস্ব ফ্রন্টিয়ার মডেল, হালকা ব্যক্তিগত ব্যবহারের জন্য একটি ফ্রি টিয়ার।

  1. console.mistral.ai-এ যান এবং একটি অ্যাকাউন্ট তৈরি করুন।
  2. API Keys → Create new key, কপি করুন।
বেস অ্যাড্রেসhttps://api.mistral.ai/v1
চেষ্টা করার জন্য মডেল (হাতে টাইপ করলে)mistral-small-latest

OpenRouter

একটি key, একটি বিল, একটি মাত্র অ্যাড্রেসের মাধ্যমে অন্য কয়েক ডজন কোম্পানির মডেলে (অনেক ফ্রি মডেলও সহ) অ্যাক্সেস — আলাদা আলাদা অ্যাকাউন্ট সামলানোর বদলে একসাথে কয়েকটি চেষ্টা করতে চাইলে এটি একটি ভালো অপশন।

  1. openrouter.ai-এ যান এবং সাইন ইন করুন।
  2. Keys → Create Key, কপি করুন।

Google Gemini

Google-এর নিজস্ব মডেল, তাদের OpenAI-কম্প্যাটিবল অ্যাড্রেসের মাধ্যমে পাওয়া যায়।

  1. aistudio.google.com/apikey-এ যান এবং একটি Google অ্যাকাউন্ট দিয়ে সাইন ইন করুন।
  2. Create API key, কপি করুন।

2. KattuOna-এ এটি লেখা

KattuOna → Settings → AI ইঞ্জিন → API key ব্যবহার করুন খুলুন, তারপর পূরণ করুন:

  • বেস অ্যাড্রেস — আপনি বেছে নেওয়া প্রোভাইডারের জন্য উপরের টেবিলের ঠিক অ্যাড্রেসটি।
  • API key — আপনি এখন কপি করা key।
  • মডেল — উপরের অ্যাড্রেস ও key পূরণ করার পর উপলব্ধ মডেল দেখুন-এ ট্যাপ করুন, এবং KattuOna প্রোভাইডার থেকে ফিরে পাওয়া লাইভ লিস্ট থেকে একটি বেছে নিন। এই ফিল্ড পূরণ করার এটিই ভরসাযোগ্য উপায়, কারণ এটি সবসময় সেই প্রোভাইডার আপনার key-র জন্য এখন কী দিচ্ছে তা প্রতিফলিত করে — কোনো পেজে লেখা পুরোনো হয়ে যেতে পারে এমন একটি নাম নয়।

সেভ করুন ও টেস্ট করুন-এ ট্যাপ করুন — KattuOna একটি ছোট টেস্ট মেসেজ পাঠায় এবং key, অ্যাড্রেস, বা মডেল ভুল থাকলে আপনাকে তখনই জানায়।

খরচ: উপরের প্রতিটি প্রোভাইডার আপনার নিজের ব্যবহারের ভিত্তিতে বিল করে (বা রেট-লিমিট করে)। KattuOna-র ডেভেলপারের আপনাকে কত চার্জ করা হচ্ছে তার উপর কোনো দৃষ্টি বা নিয়ন্ত্রণ নেই — শুরু করার আগে প্রতিটি প্রোভাইডারের নিজস্ব প্রাইসিং পেজ দেখে নিন, এবং আপনি খরচ নিয়ে সচেতন হলে ব্যবহারের উপর চোখ রাখুন।
