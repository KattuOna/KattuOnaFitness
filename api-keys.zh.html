为 KattuOna 获取 API key

适合那些更愿意直接向某家公司付费使用 AI,而不想自己运行服务器或使用 KattuOna 内置选项的人。

KattuOna 的"使用 API key"选项可以与任何其 API 采用通用 OpenAI 聊天格式的公司配合使用 — 如今,这已经是大多数公司的做法。从下面选一个,注册,创建一个 key,然后把它(连同该服务商的基础地址)粘贴到 KattuOna → 设置 → AI 引擎 → 使用 API key中。

你的 key 只会保存在你的手机上。KattuOna 会直接把它发送给你选择的那家公司,就像任何应用都会做的那样 — KattuOna 的开发者永远不会看到它,也不会看到使用它进行的对话。

关于模型名称：下面的每家公司都会随着时间淘汰旧模型、增加新模型,所以本页上印出的某个模型名称 以后可能会失效(本页的早期版本就发生过这种情况,当时列出的一个 Gemini 模型后来被 Google 移除了)。在 KattuOna 中输入好基础地址 和 key 之后,点一下设置 → AI 引擎中就在那里的浏览可用模型 — KattuOna 会直接向该服务商询问,当下你的 key 能使用哪些模型,并让你点选其中一个,而不必输入一个可能已经过时的名字。下面给出的模型名称只是一个起点,供你愿意自己输入时参考。

1. 选择一个服务商并获取 key

OpenAI

ChatGPT 背后的公司。可靠,广泛使用,按用量计费。

  1. 前往 platform.openai.com 创建一个账号。
  2. 在Billing下添加一种付款方式(API 用量与你可能拥有的任何 ChatGPT 订阅是分开计费的)。
  3. 前往API keys,点击Create new secret key,并立刻复制它 — 它只会显示一次。
基础地址https://api.openai.com/v1
可以尝试的模型(如果想手动输入)gpt-4o-mini(快速且便宜)

Groq

响应极快,免费额度丰厚,模型选择较少。

  1. 前往 console.groq.com,用 Google 或 GitHub 登录。
  2. API Keys → Create API Key,给它起个名字,复制它。
基础地址https://api.groq.com/openai/v1
可以尝试的模型(如果想手动输入)llama-3.3-70b-versatile

Together AI

开源模型选择丰富,按量付费,起步时附带少量免费额度。

  1. 前往 api.together.ai 注册。
  2. Settings → API Keys,复制默认的 key,或创建一个新的。
基础地址https://api.together.xyz/v1
可以尝试的模型(如果想手动输入)meta-llama/Llama-3.3-70B-Instruct-Turbo

Mistral

法国 AI 实验室,拥有自己的前沿模型,为轻度个人使用提供免费层级。

  1. 前往 console.mistral.ai 创建一个账号。
  2. API Keys → Create new key,复制它。
基础地址https://api.mistral.ai/v1
可以尝试的模型(如果想手动输入)mistral-small-latest

OpenRouter

一个 key,一张账单,通过单一地址即可访问数十家其他公司的模型(其中许多是免费的) — 如果你想在不折腾多个独立账号的情况下尝试多种模型,这是个不错的选择。

  1. 前往 openrouter.ai 登录。
  2. Keys → Create Key,复制它。
基础地址https://openrouter.ai/api/v1
可以尝试的模型(如果想手动输入)meta-llama/llama-3.3-70b-instruct(或加上 :free 获取一个免费选项)

Google Gemini

Google 自己的模型,可通过其 OpenAI 兼容地址访问。

  1. 前往 aistudio.google.com/apikey,用一个 Google 账号登录。
  2. Create API key,复制它。
基础地址https://generativelanguage.googleapis.com/v1beta/openai
可以尝试的模型(如果想手动输入)gemini-3.8-flash — 但 Google 更改/淘汰这些模型名称的速度比大多数公司都快,所以在这里使用"浏览可用模型"特别值得

2. 在 KattuOna 中输入

打开 KattuOna → 设置 → AI 引擎 → 使用 API key,然后填写:

  • 基础地址 — 对应你所选服务商在上表中的确切地址。
  • API key — 你刚复制的那个 key。
  • 模型 — 在上面的地址和 key 填好之后,点一下浏览可用模型, 从 KattuOna 收到的服务商实时列表中选一个。这是填写这一项的可靠方式,因为它始终反映该服务商当下为你的 key 提供的内容 — 而不是页面上印出的、可能已经过时的名字。

点一下保存并测试 — KattuOna 会发送一条简短的测试消息,并立即告诉你 key、地址或模型是否有误。

费用：上面每一家服务商都会按你自己的用量计费(或限速)。 KattuOna 的开发者无法看到或控制你被收取的费用 — 在开始之前请查看每家服务商自己的定价页面,如果你很在意成本, 请留意自己的用量。
