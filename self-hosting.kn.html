KattuOna ಗಾಗಿ ನಿಮ್ಮ ಸ್ವಂತ AI ಸರ್ವರ್ ಚಲಾಯಿಸಿ

AI ಕೋಚ್‌ಗಾಗಿ ಬೇರೊಬ್ಬರ ಸರ್ವರ್ ಮೇಲೆ ಅವಲಂಬಿಸಲು ಇಚ್ಛಿಸದ ಜನರಿಗಾಗಿ.

KattuOna ದ AI ವೈಶಿಷ್ಟ್ಯಗಳು (ಕೋಚ್ ಚಾಟ್, ಆಹಾರ/ವ್ಯಾಯಾಮ ಲುಕಪ್‌ಗಳು, ಊಟದ ಐಡಿಯಾಗಳು, ರೆಡಿನೆಸ್ ಚೆಕ್, ಪ್ರೋಗ್ರಾಂ ಬಿಲ್ಡರ್) ಅದೇ ಸರಳ ಪ್ರೋಟೋಕಾಲ್ ಮಾತನಾಡುವ ಯಾವುದೇ ಸರ್ವರ್ ಜೊತೆ ಮಾತನಾಡಬಲ್ಲವು — ಆಪ್‌ನಲ್ಲಿ ಬಿಲ್ಟ್-ಇನ್ ಆಗಿರುವ ಒಂದೇ ಅಲ್ಲ. ಈ ಪೇಜ್ ಆ ಸರ್ವರ್ ಅನ್ನು ಸ್ವತಃ ಚಲಾಯಿಸಲು ಇಚ್ಛಿಸುವ ಯಾರಿಗಾದರೂ ಆಗಿದೆ: ಒಂದು ಬಿಡುವಿರುವ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ, ಒಂದು ಹೋಮ್ ಸರ್ವರ್‌ನಲ್ಲಿ, ಒಂದು ಸಣ್ಣ VPS ನಲ್ಲಿ, ನಿಮ್ಮ ಬಳಿ ಇರುವ ಯಾವುದೇ. ನಂತರ ನಿಮ್ಮ ಪ್ರಶ್ನೆಗಳು ಮತ್ತು ನಿಮ್ಮ ಫಿಟ್‌ನೆಸ್ ಡೇಟಾ ಕೇವಲ ನೀವು ನಿಯಂತ್ರಿಸುವ ಒಂದು ಮೆಷೀನ್‌ಗೆ ಮಾತ್ರ ಹೋಗುತ್ತವೆ, ಇದು ಒಂದು ಫ್ರೀ ಲೋಕಲ್ AI ಮಾಡೆಲ್ ಚಲಾಯಿಸುತ್ತದೆ (ಯಾವುದೇ ಸಬ್‌ಸ್ಕ್ರಿಪ್ಷನ್ ಇಲ್ಲ, ಮಧ್ಯೆ ಯಾವುದೇ ಕಂಪನಿ ಇಲ್ಲ).

ನಿಮಗೆ ಕೋಡ್ ಬರೆಯುವುದು ಗೊತ್ತಿರಬೇಕಾಗಿಲ್ಲ. ನಿಮಗೆ ಒಂದು ಕಂಪ್ಯೂಟರ್ ಬೇಕು ಅದು ಆನ್ ಆಗಿ ಇರಬಲ್ಲದು (ಅಥವಾ ನೀವು AI ಬಳಸಲು ಇಚ್ಛಿಸಿದಾಗ ಆನ್ ಮಾಡಬಹುದಾದ), ಮತ್ತು ಒಂದು AI ಕೋಡಿಂಗ್ ಅಸಿಸ್ಟೆಂಟ್ — ಉದಾಹರಣೆಗೆ Claude Code — ಅದು ನಿಮಗಾಗಿ ಅದರ ಮೇಲೆ ಕಮಾಂಡ್‌ಗಳನ್ನು ಚಲಾಯಿಸಬಲ್ಲದು. ಕೆಳಗಿನ ಪ್ರಾಂಪ್ಟ್ ಆ ಅಸಿಸ್ಟೆಂಟ್‌ಗೆ ಏನನ್ನು ನಿರ್ಮಿಸಬೇಕು ಎಂದು ನಿಖರವಾಗಿ ಹೇಳುತ್ತದೆ.

1. ಕೊನೆಯಲ್ಲಿ ನಿಮ್ಮ ಬಳಿ ಏನಿರುತ್ತದೆ

  • ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಚಲಾಯಿಸುವ ಒಂದು ಚಿಕ್ಕ, ಫ್ರೀ ಲೋಕಲ್ AI ಮಾಡೆಲ್ (Ollama ಮೂಲಕ), ಇದರಿಂದ ಒಂದು ಪ್ರಶ್ನೆಗೆ ಉತ್ತರಿಸಲು ನಿಮ್ಮ ನೆಟ್‌ವರ್ಕ್‌ನಿಂದ ಏನೂ ಹೊರಗೆ ಹೋಗುವುದಿಲ್ಲ.
  • ಇದರ ಮುಂದೆ ಒಂದು ಚಿಕ್ಕ ಗೇಟ್‌ವೇ ಪ್ರೋಗ್ರಾಂ, KattuOna ತಲುಪಬಲ್ಲ, ಇದು ಉತ್ತರಿಸುವ ಮೊದಲು ಪ್ರತಿ ವ್ಯಕ್ತಿಯ ಸ್ವಂತ ಆಕ್ಸೆಸ್ key ಪರಿಶೀಲಿಸುತ್ತದೆ.
  • ಇದನ್ನು ಬಳಸುವ ಪ್ರತಿ ವ್ಯಕ್ತಿಗೆ (ನೀವು, ನಿಮ್ಮ ಸಂಗಾತಿ, ಪ್ರತಿ ಕುಟುಂಬ ಸದಸ್ಯ) ಒಂದು ಆಕ್ಸೆಸ್ key — ಪ್ರತಿ key ಕೇವಲ ಒಂದು ಹೆಸರು ಮತ್ತು ಒಂದು ರ್ಯಾಂಡಮ್ ಸ್ಟ್ರಿಂಗ್, ಸೃಷ್ಟಿಸಲು ಅಥವಾ ಅಳಿಸಲು ಸುಲಭ.
  • ನೀವು ಹೊರಗಿದ್ದಾಗ ನಿಮ್ಮ ಹೋಮ್ ನೆಟ್‌ವರ್ಕ್‌ನ ಹೊರಗಿನಿಂದ ಇದನ್ನು ತಲುಪುವ ಒಂದು ವಿಧಾನ, ನೀವು ಇಚ್ಛಿಸಿದರೆ (Tailscale ನಂತಹ ಒಂದು ಟೂಲ್ ಸುಲಭ ವಿಧಾನ — ಇದು ನಿಮ್ಮ ಹೋಮ್ ಕಂಪ್ಯೂಟರ್‌ಗೆ ಒಂದು ಗೋಪ್ಯ ವಿಳಾಸ ಕೊಡುತ್ತದೆ, ಇದನ್ನು ನಿಮ್ಮ ಸ್ವಂತ ಡಿವೈಸ್‌ಗಳು ಮಾತ್ರ ತಲುಪಬಲ್ಲವು, ಸಾರ್ವಜನಿಕ ಇಂಟರ್ನೆಟ್‌ಗೆ ಯಾವುದೇ ಪೋರ್ಟ್‌ಗಳನ್ನು ತೆರೆಯದೆ).

2. ನಿಮಗೆ ಏನು ಬೇಕಾಗುತ್ತದೆ

  • ನೀವು ಚಲಾಯಿಸುತ್ತಾ ಬಿಡಬಹುದಾದ ಒಂದು ಕಂಪ್ಯೂಟರ್ (ಒಂದು ಚಿಕ್ಕ ಮಾಡೆಲ್‌ಗೆ ಒಂದು ಹಳೆಯ ಲ್ಯಾಪ್‌ಟಾಪ್ ಕೂಡ ಕೆಲಸ ಮಾಡುತ್ತದೆ). Linux, macOS ಅಥವಾ Windows (WSL ಜೊತೆ) ಎಲ್ಲವೂ ಕೆಲಸ ಮಾಡುತ್ತವೆ.
  • ಅಲ್ಲಿ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಲಾದ ಒಂದು AI ಕೋಡಿಂಗ್ ಅಸಿಸ್ಟೆಂಟ್ ಅದು ನಿಮ್ಮ ಹೆಸರಿನಲ್ಲಿ ಶೆಲ್ ಕಮಾಂಡ್‌ಗಳನ್ನು ಚಲಾಯಿಸಬಲ್ಲದು — Claude Code ಒಂದು ನೇರ ಆಯ್ಕೆ, ಆದರೆ ಅದೇ ಸಾಮರ್ಥ್ಯ ಹೊಂದಿರುವ ಯಾವುದೇ ಅಸಿಸ್ಟೆಂಟ್ ಕೆಲಸ ಮಾಡುತ್ತದೆ.
  • ಸುಮಾರು 20–30 ನಿಮಿಷಗಳು.

3. ಪ್ರಾಂಪ್ಟ್

ಸರ್ವರ್ ಚಲಾಯಿಸುವ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಒಂದು ಟರ್ಮಿನಲ್ ತೆರೆಯಿರಿ, ನಿಮ್ಮ AI ಕೋಡಿಂಗ್ ಅಸಿಸ್ಟೆಂಟ್ ಅನ್ನು ಒಂದು ಖಾಲಿ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಪ್ರಾರಂಭಿಸಿ, ಮತ್ತು ಕೆಳಗಿನ ಪೂರ್ಣ ಬಾಕ್ಸ್ ಅನ್ನು ನಿಮ್ಮ ಮೊದಲ ಮೆಸೇಜ್ ಆಗಿ ಪೇಸ್ಟ್ ಮಾಡಿ. ಇದು KattuOna ಗೆ ಬೇಕಾದ ನಿಖರ ಚಿಕ್ಕ HTTP ಸೇವೆಯನ್ನು ವಿವರಿಸುತ್ತದೆ, ಇದರಿಂದ ಅಸಿಸ್ಟೆಂಟ್ ಇದನ್ನು ನಿರ್ಮಿಸಬಲ್ಲದು, ಟೆಸ್ಟ್ ಮಾಡಬಲ್ಲದು, ಮತ್ತು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಪ್ರಾರಂಭವಾಗಲು ಸೆಟ್ ಮಾಡಬಲ್ಲದು.

ಇದನ್ನು ನಿಮ್ಮ ಲೋಕಲ್ AI ಅಸಿಸ್ಟೆಂಟ್‌ಗೆ ಪೇಸ್ಟ್ ಮಾಡಿ 
I want to set up a small self-hosted AI server on this computer, for a fitness app called KattuOna to
talk to. Please do all of the following, explaining each step as you go, and actually run the
commands yourself rather than just telling me what to run:

1. Install Ollama (https://ollama.com) if it isn't already installed, and pull a small, fast
   instruction-tuned model suitable for CPU use (something in the 1-4B parameter range, such as
   llama3.2:3b-instruct-q4_K_M or a similarly sized alternative you judge to be a good fit for this
   machine's hardware). Confirm Ollama answers a test prompt on localhost:11434 before moving on.

2. Write a small HTTP gateway program (Python standard library only, no extra dependencies beyond
   what's already installed) that:
   - Listens on a local port of your choice (pick one not already in use, e.g. 8766, and tell me
     which).
   - Exposes POST /chat/completions, accepting a JSON body shaped like an OpenAI-style chat
     completion request: {"model": "...", "messages": [{"role": "...", "content": "..."}], ...}.
     Forward the messages to the local Ollama model and return a response in the same
     OpenAI-compatible shape: {"choices": [{"message": {"role": "assistant", "content": "..."}}]}.
   - Requires an `Authorization: Bearer ` header on every request. Keep a plain text file of
     valid keys, one per line, formatted as "name key" (e.g. "alex 7f3a9c2b1e..."), stored
     somewhere only this machine's admin can read (not world-readable). Reject requests with a
     missing or wrong key with HTTP 401, and don't log the key itself anywhere.
   - Caps request body size at a sane limit (e.g. 50KB) and returns 413 if exceeded.
   - Logs only minimal metadata per request (which person's key was used, timestamp, how long it
     took) -- never the message content, since this may include personal health/fitness details.
   - Add a small command-line helper (or a few short shell scripts) to add a new key for a person
     ("add-key NAME" -- generates a random key, appends "NAME key" to the keys file, prints the new
     key once so I can copy it), to remove one ("revoke NAME" -- deletes that person's line), and to
     list current names without printing their keys ("list-keys").

3. Set this gateway up as a service that starts automatically when the computer boots/restarts
   (systemd on Linux, launchd on macOS, or Task Scheduler / NSSM on Windows -- whichever fits this
   machine), and start it now.

4. Test it end-to-end: create one key for me, send a real chat request with it using curl and
   confirm a sensible model reply comes back, send a request with a wrong key and confirm I get
   401, and send an oversized request and confirm I get 413.

5. Tell me, in plain terms: the port number it's listening on, exactly how to run add-key / revoke /
   list-keys afterwards, and where the keys file lives. If I want to reach this server from outside
   my home network, suggest installing Tailscale (https://tailscale.com) and tell me the address
   KattuOna should use once that's set up -- don't open any ports directly on my router.

Please actually install, write, test and start all of this yourself rather than just giving me
instructions to run manually, and show me the real output of each test so I can see it worked.

ನೀವು ಬದಲಾಯಿಸಬೇಕಾದ ಯಾವುದೇ ವಿವರಗಳನ್ನು ಬದಲಿಸಿ (ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್ ನಿಧಾನ ಅಥವಾ ವೇಗವಾಗಿದ್ದರೆ ಬೇರೆ ಮಾಡೆಲ್ ಗಾತ್ರ, ಬೇರೆ ಪೋರ್ಟ್, ಇತ್ಯಾದಿ) ಇದನ್ನು ಪೇಸ್ಟ್ ಮಾಡುವ ಮೊದಲು. ನಿಮ್ಮ ಅಸಿಸ್ಟೆಂಟ್ ನಿಮ್ಮ ನಿರ್ದಿಷ್ಟ ಮೆಷೀನ್ ಬಗ್ಗೆ ಒಂದೆರಡು ಫಾಲೋ-ಅಪ್ ಪ್ರಶ್ನೆಗಳನ್ನು ಕೇಳಬಹುದು — ಇದು ಸಾಮಾನ್ಯ, ಅವುಗಳಿಗೆ ಉತ್ತರಿಸಿ ಮತ್ತು ಇದು ಮುಂದುವರಿಯಲು ಬಿಡಿ.

4. KattuOna ಅನ್ನು ಇದರತ್ತ ಗುರಿ ಮಾಡುವುದು

ನಿಮ್ಮ ಅಸಿಸ್ಟೆಂಟ್ ವಿಳಾಸ ಮತ್ತು ಪೋರ್ಟ್ ಅನ್ನು ಹಿಂತಿರುಗಿಸಿದ ನಂತರ, KattuOna → Settings → AI ಎಂಜಿನ್ → ಬೇರೊಂದು ಸರ್ವರ್ ತೆರೆಯಿರಿ, ಮತ್ತು ದಾಖಲಿಸಿ:

  • ವಿಳಾಸ — ಉದಾಹರಣೆಗೆ, ನೀವು Tailscale ಬಳಸುತ್ತಿದ್ದರೆ http://100.x.x.x:8766, ಅಥವಾ ನೀವು ಇದನ್ನು ಮನೆಯಲ್ಲಿ ಮಾತ್ರ ಬಳಸುತ್ತಿದ್ದರೆ ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನ ಲೋಕಲ್ ವಿಳಾಸ ಜೊತೆ ಪೋರ್ಟ್.
  • Key — ನಿಮ್ಮ ಅಸಿಸ್ಟೆಂಟ್ ನಿಮಗಾಗಿ (ಅಥವಾ ಯಾವ ಕುಟುಂಬ ಸದಸ್ಯನ ಫೋನ್ ಸೆಟ್ ಮಾಡಲಾಗುತ್ತಿದೆಯೋ ಅವರಿಗಾಗಿ) ಸೃಷ್ಟಿಸಿದ key.

ಅದೇ ಸ್ಕ್ರೀನ್‌ನಿಂದ ಅದನ್ನು ಬಿಡುವ ಮೊದಲು ಸಂಪರ್ಕವನ್ನು ಟೆಸ್ಟ್ ಮಾಡಿ.

5. ಜನರನ್ನು ಸೇರಿಸುವುದು ಅಥವಾ ತೆಗೆಯುವುದು

ನಿಮ್ಮ ಸರ್ವರ್ ಬಳಸುವ ಪ್ರತಿ ವ್ಯಕ್ತಿಗೂ ಅವರ ಸ್ವಂತ key ಇರಬೇಕು, ಇದರಿಂದ ನೀವು ಅವರನ್ನು ನಿಮ್ಮ ಲಾಗ್‌ಗಳಲ್ಲಿ ಬೇರೆಬೇರೆಯಾಗಿ ಗುರುತಿಸಬಹುದು ಮತ್ತು ನಂತರ ಬೇರೆ ಯಾರ ಮೇಲೂ ಪ್ರಭಾವ ಬೀಳಿಸದೆ ಒಬ್ಬ ವ್ಯಕ್ತಿಯ ಪ್ರವೇಶವನ್ನು ತೆಗೆಯಬಹುದು.

ಯಾರನ್ನಾದರೂ ಸೇರಿಸಿ

ಸರ್ವರ್ ಚಲಾಯಿಸುವ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ (ಅಥವಾ SSH ಮೂಲಕ), ನಿಮ್ಮ ಅಸಿಸ್ಟೆಂಟ್ ಸೆಟ್ ಮಾಡಿದ ಹೆಲ್ಪರ್ ಚಲಾಯಿಸಿ, ಉದಾಹರಣೆಗೆ:

add-key NAME

ಇದು ಒಂದು ಹೊಸ key ಅನ್ನು ಒಂದೇ ಬಾರಿ ತೋರಿಸುತ್ತದೆ. ಇದನ್ನು ಆ ವ್ಯಕ್ತಿಯ KattuOna ಆಪ್‌ನಲ್ಲಿ Settings → AI ಎಂಜಿನ್ → ಬೇರೊಂದು ಸರ್ವರ್‌ಗೆ ಹಾಕಿ.

ಯಾರನ್ನಾದರೂ ತೆಗೆಯಿರಿ

revoke NAME

ಅವರ key ಕೂಡಲೇ ಕೆಲಸ ಮಾಡುವುದನ್ನು ನಿಲ್ಲಿಸುತ್ತದೆ. ಹೊಸ key ದಾಖಲಿಸುವ ವರೆಗೆ, ಅವರ KattuOna ಆಪ್ ಒಂದು ಕನೆಕ್ಷನ್ ಎರರ್ ತೋರಿಸುತ್ತದೆ.

ಈಗ ಯಾರಿಗೆ ಪ್ರವೇಶ ಇದೆ ಎಂದು ನೋಡಿ

list-keys

ಇದು ಕೇವಲ ಹೆಸರುಗಳನ್ನು ತೋರಿಸುತ್ತದೆ, ಎಂದಿಗೂ keys ಗಳನ್ನು ಅಲ್ಲ, ಇದರಿಂದ ಯಾರ key ಅನ್ನು ಬಹಿರಂಗಪಡಿಸದೆ ಯಾರು ಸೆಟಪ್ ಆಗಿದ್ದಾರೆ ಎಂದು ನೀವು ದೃಢಪಡಿಸಬಹುದು.
